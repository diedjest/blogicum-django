# Blogicum

Blogicum — это полнофункциональное веб-приложение для ведения блогов, разработанное на фреймворке Django. Проект предоставляет платформу для публикации постов, их категоризации, добавления геотегов и комментирования. 

## Ключевые возможности

*   **Управление публикациями:** Пользователи могут создавать, редактировать, просматривать и удалять свои посты. Поддерживается загрузка изображений (с использованием библиотеки `Pillow`) и указание местоположения.
*   **Категоризация контента:** Посты группируются по категориям (например, "Здоровье", "Путешествия", "Работа") для удобной навигации.
*   **Система комментариев:** Зарегистрированные пользователи могут оставлять комментарии к постам, а также редактировать и удалять собственные комментарии.
*   **Аутентификация и профили:** Полноценная система регистрации, входа, выхода и восстановления пароля. У каждого пользователя есть профиль с его публикациями.
*   **Управление доступом (Permissions):** Разграничение прав доступа. Редактировать и удалять посты или комментарии может только их автор или администратор. Неопубликованные и отложенные посты видны только авторам.
*   **Пагинация:** Лента постов разбита на страницы (по 10 постов) для оптимизации загрузки.
*   **Обработка ошибок:** Настроены кастомные шаблоны для ошибок 403 (CSRF failure), 404 (Not Found) и 500 (Server Error).

## Стек технологий

*   **Backend:** Python 3, Django 3.2
*   **База данных:** SQLite (для разработки и тестирования)
*   **Frontend:** HTML, CSS, Bootstrap 5 (`django-bootstrap5`)
*   **Тестирование:** `pytest`, `pytest-django`, `mixer` (генерация фикстур)

## Покрытие тестами

Проект имеет глубокое покрытие автоматизированными тестами, проверяющими бизнес-логику и безопасность:
*   **Доступы (Permissions):** Проверка того, что неавторизованные пользователи или не-авторы не могут редактировать/удалять чужой контент.
*   **Отображение контента:** Проверка логики публикации (скрытие неопубликованных или отложенных постов из общих лент).
*   **Валидация форм:** Проверка создания и редактирования постов и комментариев.

## Запуск проекта

1. Клонируйте репозиторий и перейдите в папку проекта.
2. Создайте и активируйте виртуальное окружение:
   ```bash
   python -m venv venv
   source venv/bin/activate  # Для Linux/macOS
   # или venv\Scripts ctivate для Windows
   ```
3. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
4. Примените миграции базы данных:
   ```bash
   python manage.py migrate
   ```
5. Запустите сервер разработки:
   ```bash
   python manage.py runserver
   ```
   Проект будет доступен по адресу `http://127.0.0.1:8000/`.
